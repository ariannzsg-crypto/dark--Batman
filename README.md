من می‌خوام یک اپ اندروید به اسم Radx بسازم که به عنوان کلاینت VPN/پروکسی کار کنه.
سبک و تجربه کاربری‌اش باید شبیه اپ‌های معروفی مثل v2rayNG، Happ و Hiddify باشه (ساده، سریع و کاربردی).
نیازمندی‌های اصلی:

اپ باید بتونه کانفیگ‌های پروکسی/VPN رو ایمپورت و اجرا کنه (Clash Meta YAML، sing-box JSON، VMess، VLESS، Trojan، Shadowsocks و لینک سابسکریپشن).
از هسته sing-box یا Clash Meta استفاده کنه.
رابط کاربری ساده، تمیز و دارک‌تم داشته باشه (شبیه v2rayNG و Happ).
قابلیت‌های مورد نیاز:
وارد کردن کانفیگ از فایل، پیست کردن متن کانفیگ یا لینک سابسکریپشن
دکمه اتصال / قطع اتصال بزرگ و واضح
نمایش وضعیت اتصال (متصل / قطع)
لیست نودها با امکان انتخاب سریع
امکان آپدیت سابسکریپشن
نمایش آمار ترافیک (آپلود و دانلود)
کپی کردن لینک یا اشتراک‌گذاری کانفیگ
تنظیمات پایه (مثل انتخاب هسته، حالت تونل و ...)
